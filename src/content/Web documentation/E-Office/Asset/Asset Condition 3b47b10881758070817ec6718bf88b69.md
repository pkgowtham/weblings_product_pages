# Asset Condition

![Asset Condition](Asset%20Condition/e-office-asset-asset-condition.png)

The **Asset Conditions** screen allows you to create and manage the different conditions that can be assigned to organizational assets. Asset conditions help identify the current state of an asset, making it easier to track maintenance, repairs, replacements, and overall asset health.

From this screen, you can:

- View all asset conditions.
- Search for an asset condition.
- Create a new asset condition.
- View asset condition details.
- Edit an existing asset condition.
- Delete an asset condition.

---

# Asset Condition List

The Asset Condition table displays all available asset conditions.

The table contains the following information:

- **Name** – The asset condition name.
- **Description** – A brief description of the asset condition.
- **Actions** – View, Edit, and Delete options.

Use the **Search Asset Condition** box to quickly locate an asset condition by entering its name.

---

# Create a New Asset Condition

![Create a New Asset Condition](Asset%20Condition/e-office-asset-asset-condition_create-a-new-asset-condition.png)

To create a new asset condition, click **Add Asset Condition**.

The **New Asset Condition** page will open.

## Asset Condition Details

Enter the following information:

### Name

Enter a unique name for the asset condition.

**Examples:**

- New
- Good
- Fair
- Damaged
- Under Maintenance
- Retired

### Description

Provide a brief description explaining the asset condition.

---

## Submit

Click **Submit** to create the asset condition.

The newly created asset condition will appear in the Asset Condition list.

---

## Cancel

Click **Cancel** to return to the previous screen without saving.

---

# View Asset Condition

![View Asset Condition](Asset%20Condition/e-office-asset-asset-condition_view-asset-condition.png)

To view an asset condition:

1. Click the **View** (👁️) icon from the **Actions** column.

The details page displays:

- Name
- Description
- Created At
- Updated At
- Created By
- Updated By
- Message

This page is for viewing information only.

---

# Edit an Asset Condition

![Edit an Asset Condition](Asset%20Condition/e-office-asset-asset-condition_edit-an-asset-condition.png)

To modify an existing asset condition:

1. Click the **Edit** (✏️) icon.
2. Update:
    - Name
    - Description
3. Click **Update** to save your changes.

The updated information will immediately appear in the Asset Condition list.

If you do not wish to save your changes, click **Cancel**.

---

# Delete an Asset Condition

![Delete an Asset Condition](Asset%20Condition/e-office-asset-asset-condition_delete-an-asset-condition.png)

To remove an asset condition:

1. Click the **Delete** (🗑️) icon.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the Asset Condition. Are you sure you want to proceed?**
> 

You will have two options:

### Cancel

Returns to the previous screen without deleting the asset condition.

### Delete

Permanently removes the selected asset condition.

> **Note:** Deleting an asset condition cannot be undone. Before deleting, ensure that it is not currently assigned to any assets.
>
