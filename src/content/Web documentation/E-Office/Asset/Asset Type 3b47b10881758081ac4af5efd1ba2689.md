# Asset Type

![Asset Type](Asset%20Type/e-office-asset-asset-type.png)

The **Asset Types** screen allows you to create and manage different types of assets used within your organization. Asset types help classify assets based on their purpose and define a unique Asset ID Series for automatic asset identification.

From this screen, you can:

- View all asset types.
- Search for an asset type.
- Create a new asset type.
- View asset type details.
- Edit an existing asset type.
- Delete an asset type.

---

# Asset Type List

The Asset Type table displays all available asset types.

The table contains the following information:

- **Custom Code** – A unique identifier for the asset type.
- **Name** – The asset type name.
- **Description** – A brief description of the asset type.
- **Asset ID Series** – The prefix or series used when generating Asset IDs.
- **Actions** – View, Edit, and Delete options.

Use the **Search Asset Type** box to quickly locate an asset type by entering its **Name** or **Custom Code**.

---

# Create a New Asset Type

![Create a New Asset Type](Asset%20Type/e-office-asset-asset-type_create-a-new-asset-type.png)

To create a new asset type, click **Add Asset Type**.

The **New Asset Type** page will open.

## Asset Type Details

Enter the following information.

### Name

Enter a unique name for the asset type.

**Examples:**

- Laptop
- Desktop
- Printer
- Monitor
- Vehicle
- Mobile Device

### Custom Code

Enter a unique code for the asset type.

**Examples:**

```
LTP001
PRN001
VEH001
```

### Description

Provide a brief description of the asset type.

### Asset ID Series

Enter the Asset ID series that will be used when generating asset identification numbers.

**Examples:**

```
LAP
PRN
VEH
```

Generated Asset IDs may appear as:

```
LAP0001
LAP0002
PRN0001
```

---

## Submit

Click **Submit** to create the asset type.

The newly created asset type will appear in the Asset Type list.

---

## Cancel

Click **Cancel** to return to the previous screen without saving.

---

# View Asset Type

![View Asset Type](Asset%20Type/e-office-asset-asset-type_view-asset-type.png)

To view an asset type:

1. Click the **View** (👁️) icon from the **Actions** column.

The details page displays:

- Name
- Description
- Custom Code
- Asset ID Series
- Created At
- Updated At
- Created By
- Updated By
- Message

This page is for viewing information only.

---

# Edit an Asset Type

![Edit an Asset Type](Asset%20Type/e-office-asset-asset-type_edit-an-asset-type.png)

To modify an existing asset type:

1. Click the **Edit** (✏️) icon.
2. Update:
    - Name
    - Custom Code
    - Description
    - Asset ID Series
3. Click **Update** to save your changes.

The updated information will immediately appear in the Asset Type list.

If you do not wish to save your changes, click **Cancel**.

---

# Delete an Asset Type

![Delete an Asset Type](Asset%20Type/e-office-asset-asset-type_delete-an-asset-type.png)

To remove an asset type:

1. Click the **Delete** (🗑️) icon.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the Asset Type. Are you sure you want to proceed?**
> 

You will have two options:

### Cancel

Returns to the previous screen without deleting the asset type.

### Delete

Permanently removes the selected asset type.

> **Note:** Deleting an asset type cannot be undone. Before deleting, ensure that it is not currently assigned to any assets.
>
