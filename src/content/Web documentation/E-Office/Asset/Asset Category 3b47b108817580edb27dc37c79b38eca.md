# Asset Category

![Screenshot 2026-08-06 at 3.36.43 PM.png](Asset%20Category/Screenshot_2026-08-06_at_3.36.43_PM.png)

The **Asset Categories** screen allows you to create and manage categories for organizing your organization's assets. Categorizing assets helps simplify asset tracking, reporting, and inventory management.

From this screen, you can:

- View all asset categories.
- Search for an asset category.
- Create a new asset category.
- View asset category details.
- Edit an existing asset category.
- Delete an asset category.

---

# Asset Category List

The Asset Category table displays all available asset categories.

The table contains the following information:

- **Custom Code** – A unique identifier for the asset category.
- **Name** – The asset category name.
- **Description** – A brief description of the category.
- **Actions** – View, Edit, and Delete options.

Use the **Search Asset Category** box to quickly locate an asset category by entering its **Name** or **Custom Code**.

---

# Create a New Asset Category

![Screenshot 2026-08-06 at 3.36.58 PM.png](Asset%20Category/Screenshot_2026-08-06_at_3.36.58_PM.png)

To create a new asset category, click **Add Asset Category**.

The **New Asset Category** page will open.

## Asset Category Details

Enter the following information.

### Name

Enter a unique name for the asset category.

**Examples:**

- IT Equipment
- Office Furniture
- Vehicles
- Machinery
- Networking Devices

### Custom Code

Enter a unique code to identify the asset category.

**Examples:**

```
IT001
FUR001
VEH001
```

### Description

Provide a brief description of the asset category.

---

## Submit

Click **Submit** to create the asset category.

The newly created asset category will appear in the Asset Category list.

---

## Cancel

Click **Cancel** to return to the previous screen without saving.

---

# View Asset Category

![Screenshot 2026-08-06 at 3.37.18 PM.png](Asset%20Category/Screenshot_2026-08-06_at_3.37.18_PM.png)

To view an asset category:

1. Click the **View** (👁️) icon from the **Actions** column.

The details page displays:

- Name
- Description
- Custom Code
- Created At
- Updated At
- Created By
- Updated By
- Message

This page is for viewing information only.

---

# Edit an Asset Category

![Screenshot 2026-08-06 at 3.37.32 PM.png](Asset%20Category/Screenshot_2026-08-06_at_3.37.32_PM.png)

To modify an existing asset category:

1. Click the **Edit** (✏️) icon.
2. Update:
    - Name
    - Custom Code
    - Description
3. Click **Update** to save your changes.

The updated information will immediately appear in the Asset Category list.

If you do not wish to save your changes, click **Cancel**.

---

# Delete an Asset Category

![Screenshot 2026-08-06 at 3.37.45 PM.png](Asset%20Category/Screenshot_2026-08-06_at_3.37.45_PM.png)

To remove an asset category:

1. Click the **Delete** (🗑️) icon.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the Asset Category. Are you sure you want to proceed?**
> 

You will have two options:

### Cancel

Returns to the previous screen without deleting the asset category.

### Delete

Permanently removes the selected asset category.

> **Note:** Deleting an asset category cannot be undone. Before deleting, ensure that it is no longer assigned to any assets.
>
