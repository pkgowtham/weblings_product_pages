# Notice period

![Screenshot 2026-08-05 at 6.37.58 PM.png](Notice%20period/Screenshot_2026-08-05_at_6.37.58_PM.png)

The **Notice Period** screen allows you to create and manage notice period policies for your organization. Notice periods define the amount of notice an employee or employer must provide before ending employment.

The screen displays all available notice period policies with the following information:

- Custom Code
- Notice Period Name
- Description
- Duration
- Duration Unit (Days / Weeks / Months)
- Actions (View, Edit, Delete)

You can also use the **Search** bar to quickly find a notice period by entering its **name** or **custom code**.

---

# Create a New Notice Period

To create a new notice period, click the **Add Notice Period** button in the top-right corner of the screen.

The **New Notice Period** page will open.

Complete the following information.

## Notice Period Details

- **Notice Period Name**
- **Custom Code**
- **Description**
- **Notice Period Duration**
- **Duration Unit**
    - Days
    - Weeks
    - Months

After entering all the required information, choose one of the following options:

### Submit

Click **Submit** to create the new notice period. Once created, it will appear in the notice period list.

### Cancel

Click **Cancel** to return to the previous screen without saving any information.

---

# View Notice Period

To view a notice period:

1. Click the **View** (👁️) icon from the **Actions** column.

The details page displays the following information:

- Notice Period Name
- Description
- Custom Code
- Notice Period Duration
- Duration Unit
- Created Date & Time
- Business Unit Location
- Created By
- Updated By
- Status Message

This page is for viewing information only and cannot be edited.

---

# Edit a Notice Period

If you need to modify an existing notice period:

1. Click the **Edit** (✏️) icon from the **Actions** column.
2. The **Edit Notice Period** page will open.
3. Update any of the following information:
    - Notice Period Name
    - Custom Code
    - Description
    - Notice Period Duration
    - Duration Unit (Days / Weeks / Months)
4. Click **Update** to save your changes.

The updated information will be reflected immediately in the notice period list.

If you do not wish to save your changes, click **Cancel** to return to the previous screen without updating the notice period.

---

# Delete a Notice Period

If a notice period is no longer required:

1. Click the **Delete** (🗑️) icon from the **Actions** column.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the notice period. Are you sure you want to proceed?**
> 

You will have two options:

### Cancel

Returns to the previous screen without deleting the notice period.

### Delete

Permanently removes the selected notice period from the system.

> **Note:** Deleting a notice period cannot be undone. Before deleting, ensure that it is no longer assigned to any employees or HR policies.
>
