# Leave Type

The **Leave Type** screen allows you to create and manage the different types of leave available within your organization. Leave Types help define the categories of leave employees can request, such as Annual Leave, Sick Leave, Casual Leave, Maternity Leave, or Unpaid Leave.

The screen displays a list of all available leave types with the following information:

- Custom Code
- Leave Type Name
- Description
- Category
- Actions (View, Edit, Delete)

You can also use the **Search Leave Type** bar to quickly find a leave type by entering its **name** or **custom code**.

---

# Create a New Leave Type

![Screenshot 2026-08-06 at 10.59.53 AM.png](Leave%20Type/Screenshot_2026-08-06_at_10.59.53_AM.png)

To create a new leave type, click the **Add Leave Type** button in the top-right corner of the screen.

The **New Leave Type** page will open.

## Step 1: Enter Leave Type Details

Complete the following information.

### Category

Select the category that best describes the leave type.

**Examples:**

- Paid Leave
- Unpaid Leave
- Sick Leave
- Maternity Leave
- Paternity Leave
- Special Leave

---

### Leave Type Name

Enter a unique name for the leave type.

**Examples:**

- Annual Leave
- Casual Leave
- Sick Leave
- Earned Leave

---

### Custom Code

Enter a unique code for the leave type.

**Examples:**

- AL001
- CL001
- SL001
- EL001

---

### Description

Provide a short description explaining the purpose of the leave type.

**Example:**

> Annual Leave allows employees to take planned time off for personal reasons while continuing to receive their regular salary.
> 

---

### Carry Forward Remaining Leave Balance

If you want unused leave to be carried forward to the next leave period, enable the following option:

**☑ If selected, any remaining leave balance will be added to the new period's entitlement.**

When enabled, employees can carry forward their unused leave balance according to your organization's leave policy.

---

## Step 2: Save the Leave Type

After entering all the required information:

- Click **Submit** to create the leave type.
- Click **Cancel** to return without saving.

Once created, the leave type will appear in the Leave Type list.

---

# View Leave Type Details

![Screenshot 2026-08-06 at 11.00.10 AM.png](Leave%20Type/Screenshot_2026-08-06_at_11.00.10_AM.png)

Click the **View** (👁️) icon to open the Leave Type details page.

The details page displays:

- Leave Type Name
- Description
- Custom Code
- Category
- Carry Forward Status
- Created Date & Time
- Business Unit Location
- Created By
- Status Message

This page is for viewing information only.

---

# Edit a Leave Type

![Screenshot 2026-08-06 at 11.05.14 AM.png](Leave%20Type/Screenshot_2026-08-06_at_11.05.14_AM.png)

To update an existing leave type:

1. Click the **Edit** (✏️) icon.
2. The **Edit Leave Type** page will open.
3. Update any of the following information:
    - Category
    - Leave Type Name
    - Custom Code
    - Description
4. Click **Update** to save your changes.

The updated information will appear immediately in the Leave Type list.

If you do not want to save your changes, click **Cancel** to return without updating.

---

# Delete a Leave Type

![Screenshot 2026-08-06 at 11.05.32 AM.png](Leave%20Type/Screenshot_2026-08-06_at_11.05.32_AM.png)

To remove a leave type:

1. Click the **Delete** (🗑️) icon.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the Leave Type. Are you sure you want to proceed?**
> 

You will have two options:

- **Cancel** – Return without deleting the leave type.
- **Delete** – Permanently remove the selected leave type.

> **Note:** Deleting a leave type cannot be undone. Ensure the leave type is no longer assigned to any leave policies or employees before deleting it.
>
