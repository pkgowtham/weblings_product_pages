# FAQ

## 1. Why can't I create a new Leave Type?

### Possible Causes

- One or more required fields are empty.
- The Leave Type Name already exists.
- The Custom Code is already in use.
- A Leave Category has not been selected.
- You do not have permission to create Leave Types.

### What You Can Do

- Complete all required fields.
- Enter a unique Leave Type Name.
- Use a unique Custom Code.
- Select a Leave Category.
- Contact your system administrator if the problem continues.

---

## 2. Why can't I edit a Leave Type?

### Possible Causes

- You do not have permission to edit Leave Types.
- The Leave Type is currently locked by another process.
- Your login session has expired.

### What You Can Do

- Refresh the page and try again.
- Sign out and sign back in.
- Verify that you have the required permissions.
- Contact your administrator if the issue persists.

---

## 3. Why can't I delete a Leave Type?

### Possible Causes

- The Leave Type is assigned to one or more employees.
- The Leave Type is linked to an active leave policy.
- You do not have permission to delete Leave Types.

### What You Can Do

- Remove or update any employee assignments.
- Remove the Leave Type from active leave policies.
- Ensure you have delete permissions.
- Contact your administrator if deletion is still blocked.

---

## 4. Why is the Leave Type list not loading?

### Possible Causes

- Slow or unstable internet connection.
- The server is temporarily unavailable.
- A network interruption occurred.
- No Leave Types have been created.

### What You Can Do

- Refresh the page.
- Check your internet connection.
- Wait a few minutes and try again.
- Contact your administrator if the issue continues.

---

## 5. Why is the Search Leave Type feature not returning any results?

### Possible Causes

- The entered Leave Type Name or Custom Code does not exist.
- The search keyword contains spelling mistakes.
- Filters are limiting the search results.

### What You Can Do

- Verify the Leave Type Name or Custom Code.
- Clear any applied filters.
- Try searching with a shorter keyword.
- Refresh the page if necessary.
