# Pay Grade

The **Pay Grade** screen allows you to create and manage salary structures for your organization. A Pay Grade defines the salary components assigned to employees, including basic pay, allowances, variables, bonuses, and the associated pay scale.

The Pay Grade list displays all available pay grades with the following information:

- Custom Code
- Pay Grade Name
- Description
- Actions (View, Edit, Delete)

You can also use the **Search Pay Grade** bar to quickly find a pay grade by entering its **name** or **custom code**.

---

# Create a New Pay Grade

![Screenshot 2026-08-06 at 12.18.42 PM.png](Pay%20Grade/Screenshot_2026-08-06_at_12.18.42_PM.png)

To create a new pay grade, click the **Add Pay Grade** button in the top-right corner of the screen.

The **New Pay Grade** page will open.

## Pay Grade Details

Complete the following information:

### Basic Information

- **Pay Grade Name**
- **Custom Code**
- **Description**

### Salary Components

- **Basic Salary**
- **House Rent Allowance (HRA)**
- **Allowances**
- **Variables**
- **Bonus**
- **Pay Scale**
- **Total Amount**

The **Total Amount** is calculated based on the selected salary components and pay scale.

---

## Save or Cancel

After entering all required information:

### Submit

Click **Submit** to create the new pay grade.

The pay grade will be added to the Pay Grade list.

### Cancel

Click **Cancel** to return to the previous screen without saving.

# View Pay Grade

![Screenshot 2026-08-06 at 12.18.28 PM.png](Pay%20Grade/Screenshot_2026-08-06_at_12.18.28_PM.png)

To view a pay grade:

1. Click the **View** (👁️) icon from the **Actions** column.

The details page displays:

- Pay Grade Name
- Description
- Custom Code
- Basic Salary
- House Rent Allowance (HRA)
- Allowances
- Variables
- Bonus
- Total Amount
- Pay Scale
- Created Date & Time
- Created By
- Updated By
- Status Message

This page is for viewing information only and cannot be edited.

---

# Edit a Pay Grade

![Screenshot 2026-08-06 at 12.19.08 PM.png](Pay%20Grade/Screenshot_2026-08-06_at_12.19.08_PM.png)

To update an existing pay grade:

1. Click the **Edit** (✏️) icon.
2. The **Edit Pay Grade** page will open.
3. Update any of the following:
    - Pay Grade Name
    - Custom Code
    - Description
    - Basic Salary
    - House Rent Allowance (HRA)
    - Allowances
    - Variables
    - Bonus
    - Pay Scale
    - Total Amount
4. Click **Update** to save your changes.

The updated information will be reflected immediately in the Pay Grade list.

If you do not wish to save your changes, click **Cancel**.

---

# Delete a Pay Grade

![Screenshot 2026-08-06 at 12.19.22 PM.png](Pay%20Grade/Screenshot_2026-08-06_at_12.19.22_PM.png)

To remove a pay grade:

1. Click the **Delete** (🗑️) icon.
2. A confirmation dialog will appear.

## Confirmation Message

> **This will permanently remove the pay grade. Are you sure you want to proceed?**
> 

You will have two options:

### Cancel

Return without deleting the pay grade.

### Delete

Permanently remove the selected pay grade.

> **Note:** Deleting a pay grade cannot be undone. Ensure the pay grade is no longer assigned to employees or payroll configurations before deleting it.
>
