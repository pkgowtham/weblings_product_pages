# FAQ

### I can't create a project.

**Possible causes:**

- One or more required fields are empty.
- A client has not been selected.
- A project manager has not been selected.

**Solution:**

- Ensure all required fields are completed.
- Select a client from the **Client** dropdown.
- Select a project manager from the **Project Manager** dropdown.
- Click **Create Project** again.

---

### The client I need is not available in the dropdown.

**Possible cause:**

The client has not been added to the system.

**Solution:**

- Verify that the client exists in the **Clients** module.
- If the client is missing, create the client first.
- Return to the **Create Project** or **Edit Project** screen and select the client.

---

### The project manager is not listed.

**Possible cause:**

The employee has not been assigned as a project manager or is inactive.

**Solution:**

- Confirm that the employee is active.
- Verify the employee has the required permissions or role.
- Refresh the page and try again.

---

### I can't save changes after editing a project.

**Possible causes:**

- Required fields are missing.
- The selected values are invalid.

**Solution:**

- Review all required fields.
- Ensure a valid client and project manager are selected.
- Click **Save Changes** again.

---

### I accidentally deleted a project.

**Possible cause:**

The deletion was confirmed.

**Solution:**

- Deleted projects cannot be restored from the Projects screen.
- Contact your system administrator if the project needs to be recreated or restored.

---

### My newly created project is not displayed.

**Possible causes:**

- The page has not been refreshed.
- Filters are hiding the project.

**Solution:**

- Refresh the Projects page.
- Clear any active search or filters.
- Verify that the project was created successfully.

---

### I cannot edit or delete a project.

**Possible cause:**

You do not have the required permissions.

**Solution:**

- Contact your administrator to verify your access rights.
- Ensure you have permission to manage projects.
