# Organization Portal User Guide

Welcome to the Organization Portal.

This guide explains how to create an account, sign in, verify your email, reset your password, and access your organization.

No technical knowledge is required.


# Getting Started

![enter email (1).png](Web%20documentation/enter_email_(1).png)

Before creating an account, make sure you have:

- A valid email address
- Access to your email inbox
- A secure password
- A stable internet connection

Creating an account only takes a few minutes.
